# WebUI 迁移与真实回归说明

日期：2026-03-06

## 当前结论

WebUI 现在是正式主线：

1. 剧本、任务、音色、资产、系统、日志、导出已经形成完整工作流。
2. 桌面 GUI 进入兼容保留态，不再承接新的主线能力。
3. 是否允许桌面 GUI 进一步退场，只取决于真实环境回归结果，而不再取决于明显功能缺口。

## 迁移边界

已经迁入 WebUI 的主流程：

1. 剧本页：原文输入、角色管理、AI 分析、结构化脚本编辑、发送到任务预检。
2. 任务页：批量合成、单行运行、失败重试、最近结果恢复、结果合并导出。
3. 音色页：按角色批量改名、legacy 配置导入。
4. 资产页：transcript 状态筛选、全局绑定状态、当前音色关系。
5. 系统页：运行时状态、桥接状态、日志联动。
6. 日志页：应用日志、访问日志、崩溃日志、本地桥接日志、诊断包导出。

桌面 GUI 当前保留定位：

1. 历史用户的兼容入口。
2. 个别未迁移完的深度桌面交互兜底。
3. 问题复现和对照验证参考。

## 真实回归执行

真实回归脚本位于：

- [webui_real_regression.mjs](/Users/lilei/Desktop/voice/web_ui/scripts/webui_real_regression.mjs)

在 [web_ui](/Users/lilei/Desktop/voice/web_ui) 下执行：

```powershell
$env:WEBUI_REAL_BASE_URL="http://127.0.0.1:9880"
$env:WEBUI_REAL_MODE="no-auth"
npm run regression:real
```

可选环境变量：

```powershell
$env:WEBUI_REAL_API_KEY="your-api-key"
$env:WEBUI_REAL_BRIDGE_URL="http://127.0.0.1:9879"
$env:WEBUI_REAL_ALLOW_SYSTEM_ACTIONS="1"
$env:WEBUI_REAL_BATCH_TEXT="真实回归测试文本"
```

建议按以下四组场景分别执行：

1. 无鉴权
2. 有鉴权
3. 本地桥接模式
4. 远程服务模式

脚本固定检查：

1. `GET /api/v2/health`
2. `GET /api/v2/voices`
3. `GET /api/v2/assets/audio`
4. `POST /api/v2/pro/batch` + 轮询
5. `GET /api/v2/pro/logs/sources`
6. `GET /api/v2/pro/logs/tail`
7. `POST /api/v2/pro/logs/diagnostic-bundle`
8. 本地桥接健康检查；允许时执行 `ensure-runtime`
9. 允许时执行模型 `reload / unload`

## 签收标准

可以进入“WebUI 主线完成”状态的最低条件：

1. `npm run build` 通过。
2. `npm run smoke` 通过。
3. 四组真实回归至少各通过一次。
4. README、迁移说明和当前代码行为一致。
5. WebUI 中不再存在明显的双轨正式入口冲突。

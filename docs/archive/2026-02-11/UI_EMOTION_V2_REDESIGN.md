# 情绪管理（v2）页面 UI 优化设计（Apple 风格）
最后更新：2026-02-10  
状态：Design / 待实现  
适用页面：`ui/emotion_voices.py`（左侧“语音配置”，右侧“参考音频 assets”）

本设计聚焦你反馈的两点：字体偏小、选项框偏小，同时补齐信息层级与操作动线，让这个页面更像苹果应用那种“克制、清晰、耐看、效率高”的管理页。

---

## 1. 现状问题（来自截图与当前实现）
- 视觉密度不均：左侧卡片留白过大，右侧上方按钮过多但不成组，主表格内容区显得“空且小”。
- 字号与控件高度偏小：`LineEdit/ComboBox/SpinBox` 高度偏矮，Tab 标签、表格行高偏小，长时间使用不舒适。
- 信息结构不清：用户需要同时理解“角色”“情绪”“voice 配置”“资产列表”“绑定状态”，但页面缺少明显的主线。
- 操作入口分散：试听、绑定、解绑、删除、上传分布在不同区域，缺少“主操作”和“次操作”的层级区分。
- 过滤能力弱：角色、情绪、语言、备注、绑定状态的组合筛选与搜索不够顺手。

---

## 2. 设计目标（必须满足）
- 大字体与大控件：在 2K 屏幕下也显得“松弛好点”，不需要费眼。
- 主线明确：先选“角色”，再选“情绪”，再管理“该情绪的参考音频”，最后保存/编译 voice。
- 操作分级：常用动作一眼可见，不常用动作收进菜单，减少按钮墙。
- 快速定位：支持搜索与筛选（至少支持“按备注/文件名/asset_id 搜索”）。
- 中文交互：所有用户可见文案均为中文（按钮、提示、空状态、菜单）。

---

## 3. Apple 风格视觉规范（字号、间距、控件高度）

### 3.1 字体与字号（建议值）
- 页面标题（Subtitle）：18-20px
- 分区标题（Section）：14-16px，字重略高
- 正文与表单标签（Body）：13-14px
- 辅助信息（Caption）：12px，灰度更浅

### 3.2 控件高度（建议统一）
- `LineEdit/ComboBox/SpinBox/PushButton`：40px（最小 36px）
- `ToolButton`：32-36px
- 表格行高：36-40px
- 顶部工具栏：48-56px

### 3.3 间距与留白（建议统一）
- 页面边距：24
- 卡片内边距：18-20
- 垂直间距：12（组内）/ 18（组间）
- 分割线：尽量少，用卡片分组替代

## 4. 页面结构重排（线框图）

### 4.1 新结构总览
- 左侧：改为“角色与情绪 + voice 配置”两张卡片，减少空白，强调主线。
- 右侧：上方“工具栏 + 情绪切换”，中间“资产表格”，底部“上传区”做成更强的输入条。
- 情绪切换：用更大的分段控件替代小 Tab（或把 Tab 做成更大更像标签条）。

## 5. 交互与信息层级（按钮分组与中文文案）

### 5.1 顶部工具栏（右侧主操作）
保留 2-3 个“主操作”，其余收进“更多”菜单：
- 主操作按钮（始终可见）：
- `试听`：试听当前选中的 asset（没有选中时置灰并提示）
- `绑定到当前 voice`：把选中 asset 绑定到当前 `voice_id`
- `删除`：删除选中 asset（危险操作，弹确认）
- 更多菜单（`⋯`）：
- `从当前 voice 解绑`
- `复制 asset_id`
- `在资源管理器中打开文件`

### 5.2 情绪切换（更大、更可读）
- 默认展示 8 个常用情绪为分段按钮，字体更大，点击即切换。
- 额外情绪：
- `+ 添加情绪`：弹出输入框（中文提示），新增后立即切换并刷新 assets
- 若情绪过多：分段控件可横向滚动或折叠为“更多”下拉

### 5.3 搜索与过滤（放在表格上方）
- 搜索框（中文 placeholder）：`搜索备注/文件名/asset_id`
- 过滤项（紧凑一行）：
- `语言` 下拉：`全部 / zh / en / ja / ko`
- `绑定状态` 下拉：`全部 / 已绑定 / 未绑定`
- 可选：`仅显示当前 voice 已绑定`（一个开关）

### 5.4 Voice 配置区（左侧卡片）
- 卡片标题展示上下文：`当前 voice 配置（{角色} / {情绪}）`
- 字段层级：
- `模式` 与 `参考选择策略` 放一行，控件高度 40
- `参考文本` 与 `指令文本` 两个多行输入，默认高度更大
- 按钮区：
- 主按钮：`保存 voice`
- 次按钮：`编译`
- 开关：`编译全部参考音频`（中文替代当前 “compile all refs”）

## 6. 表格（资产列表）优化

### 6.1 列名全部中文
建议列（更像“资源库”）：
- `名称`（显示文件名或短路径）
- `备注`
- `语言`
- `时间`
- `绑定`（显示 `已绑定/未绑定`，而不是 `Y`）
- `asset_id`（末尾列，等宽字体可选，但字号不低于 12）

### 6.2 行高与字体
- 行高：36-40
- 正文字体：系统字体 13-14
- `asset_id` 可用等宽字体，但不要用 9 号（至少 12）

### 6.3 选中态与空状态
- 没有 assets 时显示空状态文案（中文）：
- `此情绪下还没有参考音频。你可以在下方选择文件并上传。`

---

## 7. 上传区优化（更像“输入条”）
- 上传区固定在表格下方，做成一条“表单输入条”，控件高度统一 40。
- 文案：
- `情绪标签` 输入框 placeholder：`例如 default / happy / ...`
- `备注` placeholder：`可选，用于搜索`
- 文件选择显示：未选择时 `未选择文件`，选中后显示文件名并可点击打开目录（可选）
- 支持拖拽（P2）：把音频文件拖到上传区即可自动填入文件并高亮“上传”

---

## 8. 分阶段落地计划（按最短闭环）

### P0（0.5-1 天，立刻变好看）
- 统一控件高度到 40（组合框、输入框、按钮、SpinBox）
- 提升全局字号（表格行高、表格字体、Tab/分段字体）
- 表格列名中文化，`linked` 改成 `绑定` 显示 `已绑定/未绑定`
- 把顶部按钮按“主操作 + 更多菜单”重排，减少按钮墙

### P1（1-2 天，结构与动线优化）
- 用更大的分段控件替换 `QTabWidget`（或把 Tab 改成大标签条）
- 表格上方增加“搜索 + 过滤（语言/绑定状态）”
- 左侧改成两张卡片并减少空白，同时显示当前上下文标题

### P2（1-2 天，像苹果且高效率）
- 上传区支持拖拽文件
- 右键菜单支持复制 `asset_id`、打开文件位置
- “仅显示当前 voice 已绑定”过滤开关
- 详情侧边预览（可选）：选中行后显示元信息（更快核对）

---

## 9. 验收标准
- 字体与控件：不需要眯眼看，连续操作 30 分钟不累。
- 操作效率：完成“选角色 -> 切情绪 -> 上传 -> 绑定 -> 保存 voice -> 编译”不需要来回找按钮。
- 可维护性：布局改动主要集中在 `ui/emotion_voices.py`，不影响 v2 API 行为。
